Categories and tags sort tasks so people can find their work. Each company has its own lists, and every project in the company uses them.

{{shots task-settings}}

## Where to find it

On the company page, tap **Task categories and tags**.

## Categories

A task has one category, such as Locations, Casting or Camera. Each company starts with 12, and admins manage the list:

- **Add**: type a name and tap **Add category**.
- **Rename**: double-tap (or double-click) the name.
- **Reorder**: drag the handle on the left. Pick-lists show categories in this order.
- **Delete**: select it and tap **Delete category**. Its tasks keep everything else and show no category.

## Tags

A task can have several tags, such as urgent, permits or vendor.

- **Anyone in the company** adds a tag by typing a new name in a task's tag box and pressing Enter, or by typing it in the Tags cell of the task table.
- **Admins** rename tags here, or select one and tap **Delete tag**.

## Using them

On a project's **Tasks** page:

- Filter the Category or Tags column to see only those tasks.
- Choose **Show › Grouped by category** to see tasks in category groups.

See [Tasks and sub-tasks](/help/project/tasks).
