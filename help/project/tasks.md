**Tasks** holds everything that has to get done on a project, from permits to wardrobe fittings. Tasks nest: a task can have sub-tasks, and those can have their own.

{{shots tasks}}

## Add a task

1. Open **Tasks** in the project's menu.
2. Type the task in **New task** and tap **Add task**.
3. The new task's form opens under the table. Fill in the rest and tap **Save**.

To add a sub-task, open the parent task's form and add it under **Sub-tasks**, or pick its parent in **Sub-task of**.

## What a task holds

| Field | Notes |
| --- | --- |
| Task | Its name |
| Status | To do, In progress, Blocked or Done |
| Priority | Low, Medium, High or Urgent |
| Assigned to | Someone on the team |
| Start and due date | Each with a time of day (Any time, Morning, Afternoon, Evening) or an exact time |
| Category | One of the company's categories |
| Tags | Any number of the company's tags |
| Location | One of the project's locations |
| Description | Details |
| Sub-task of | Moves it under another task |

## Change a task

- **In the table**: tap a dropdown cell (status, priority, person, category) to pick. Double-tap (or double-click) the name, dates, description or tags to type. Table changes save as soon as you finish.
- **In the form**: select the task, make your changes and tap **Save**. **Undo changes** puts them back.

## Notes

Any number of notes per task, under **Notes** in its form, each signed with the author and time. Only the author edits a note; the author or an admin deletes it. Every task note also shows on [Project notes](/help/project/project-notes-and-journal).

## Overdue

A task that isn't Done turns red once its due time passes: noon for Morning, 5 PM for Afternoon, midnight for Evening or no time.

## Send a summary

Tick the tasks you want, then tap **Email summary** to open your email app with them listed, or **Copy summary** to paste them anywhere. **Clear ticks** clears the ticks.

## Delete a task

In its form, tap **Delete task**. Its sub-tasks are deleted with it.
