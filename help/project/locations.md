**Locations** holds every place you're scouting or shooting. Scenes, tasks, elements and shoot days point to these locations, and call sheets print their details.

{{shots locations}}

## Add a location

1. Open **Locations** in the project's menu.
2. Type the name and tap **Add location**.
3. Fill in the form and tap **Save**.

## What a location holds

| Field | Notes |
| --- | --- |
| Status | Considering, Confirmed or Not using |
| Description | What it is and which parts you'll use |
| Address | Tap **Open in maps**, or the Map column, to open it in your device's maps app |
| Contact name, email and phone | The on-site contact, printed on call sheets |
| Parking | Where cast and crew park |
| Nearest hospital | Printed on call sheets for safety |

## Not using

Locations marked **Not using** are hidden from the list and aren't offered for tasks. Tick **Show the ones we're not using** to see them again.

## Where locations show up

- **Scenes**: each scene's location.
- **Tasks**: a task's location, with an Open in maps link.
- **Shoot days**: a day's locations, in order. Weather is looked up for the first one.
- **Call sheets**: each location's address, parking, contact and nearest hospital.

## Delete a location

Whoever added it, or an admin, taps **Delete location** in its form. Anyone on the project can add and change locations.
