A project is one film, short or series. Each has its own team, tasks, scenes, locations and shoot days. Its **Overview** page shows where it stands at a glance.

{{shots overview}}

## Create a project

1. On the company page, under **Projects**, type the name in **New project name**.
2. Tap **Create project**.
3. The project opens with its details form. Fill in what you know and tap **Save**.

Only company admins create projects.

## Project details

| Field | What it's for |
| --- | --- |
| Name | The working title |
| Status | Development, Pre-production, Production, Post-production, Released, On hold or Cancelled |
| Start and end dates | When the project runs |
| Logline | The story in one sentence |
| Description | Anything else worth knowing |

Admins change them with **Edit project** on the Overview, or in the Projects table on the company page (tap a status to pick one).

## The Overview page

- **Details**: the logline, status and dates.
- **At a glance**: counts of open and overdue tasks, locations and people, each linking to its page.
- **Scenes and shots**: scenes, pages and shots done so far.
- **Shoot days**: the next shoot day (or "Shooting today") with its crew call, shooting call, lunch and scenes, and a link to its call sheet. It warns when that day's call sheet hasn't been sent.
- **Coming up**: the next tasks due.

## Moving around a project

The project's pages are in its menu: Overview, Tasks, Scenes, Characters, Elements, Shoot days, Locations, Team, Project notes, Journal and, for admins, Activity. The menu runs down the left on an iPad or computer, and across the top on a phone. Under it are links back to the company.

## Delete a project

Company admins tap **Delete project** in the Edit project form. Everything in the project goes with it. The Activity log keeps a record.
