Elements are the things a scene needs: props, wardrobe, hair and makeup, set dressing, vehicles, animals, effects, stunts, extras, sound and special equipment. Each element is stored once and linked to every scene that uses it.

{{shots elements}}

## Add an element

1. Open **Elements** in the project's menu.
2. Type the name and tap **Add element**.
3. Fill in the form and tap **Save element**.

You can also add one by name from a scene's form.

## What an element holds

| Field | Notes |
| --- | --- |
| Category | From the company's list |
| Status | Needed, Sourced or Ready |
| Quantity | How many |
| Owner | Who on the team is getting it |
| Character | Optional: the one character it belongs to |
| Location | Optional: the one location it stays at |
| Scenes | Every scene that uses it, each with a note |
| Description and notes | Anything else |

## Linking to scenes

Link an element to scenes in its form or in the table's Scenes dropdown, or pick elements in a scene's form. Both are the same link.

## On the call sheet

The call sheet lists the elements of the day's scenes by category, and each scene names its elements. On a personal link, the reader's own character's elements come first, marked Yours.

## Element categories

The company has 12 starter categories. Company admins add, rename and delete them in the **Element categories** section at the bottom of the page. Deleting a category keeps its elements.

## Delete an element

Whoever added it, or an admin, taps **Delete element** in its form.
