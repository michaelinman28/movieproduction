**Scenes** lists the script in order. Shoot days and call sheets are built from these scenes, so each scene is entered once and used everywhere.

{{shots scenes}}

## Add a scene

1. Open **Scenes** in the project's menu.
2. Type the scene number, such as 12 or 12A, and tap **Add scene**.
3. Its form opens under the table. Fill in the details and tap **Save scene**.

New scenes go to the end. Drag the handle at the left of a row to change the order.

## What a scene holds

| Field | Notes |
| --- | --- |
| Scene | The number, unique in the project |
| Set | For example EXT. BOND PARK - BOATHOUSE |
| I/E | INT or EXT |
| D/N | Day, night, dawn or dusk |
| Pages | In eighths: type 1 3/8, 3/8 or 2 |
| Synopsis | What happens |
| Characters | Who's in it, from the Characters page |
| Elements | Props, wardrobe and more, from the Elements page |
| Other needs | Anything that isn't an element |
| Location | Where it will be shot |
| Status | Not scheduled, Scheduled or Shot |

## Status

- A scene becomes **Scheduled** when it's put on a shoot day.
- Set it to **Shot** when it's finished.

## Characters and elements

Pick a scene's characters and elements in its form, or tick them in the table's dropdowns. These are the same links as on the Characters and Elements pages, so changing them in either place changes both. You can add a new element by name from the scene form.

## Shot list and notes

Each scene's form has a **Shot list** and **Notes**. See [Shot lists](/help/project/shot-lists).

## Delete a scene

Whoever added a scene, or an admin, taps **Delete scene** in its form. Its shots go with it.
