---
title: Who can see and change what
summary: What admins, project members, authors and link holders can each do.
order: 1
---
What you can do depends on who you are in a company and a project. The rules are enforced by the database itself, so they hold however the app is used.

## The kinds of people

| Who | Meaning |
| --- | --- |
| Company admin | Runs the company. Ticked as admin on the People list |
| Company member | In the company, not an admin |
| Project member | On a project's Team |
| Crew | A project member with a crew role, and every company admin |
| Cast | A project member who plays a character or has a Cast role |
| Author | Whoever wrote a note or added an item |
| Link holder | Anyone with a personal or shared call sheet link, signed in or not |

## Company

| Action | Who |
| --- | --- |
| Create a company | Anyone signed in |
| See the company and its people | Company members |
| Change its name and description, or delete it | Company admins |
| Add, change and remove people; send invites | Company admins |
| Change someone's name, nickname and phone | Company admins, or the person |
| Change a sign-in email | Only the person |
| Add, change and delete custom roles | Company admins |
| Manage task and element categories | Company admins |
| Add task tags | Company members |
| Rename and delete task tags | Company admins |
| See the Activity log | Company admins |

## Projects

| Action | Who |
| --- | --- |
| See a project | Its project members, and company admins |
| Create, change or delete a project | Company admins |
| Add and remove team members; set project roles | Company admins |
| Set dietary needs | The person, or company admins |
| See team member notes | Company admins, and the person they're about |

## Working lists

| Action | Who |
| --- | --- |
| Add and change tasks, scenes, shots, characters, elements and locations | Project members and company admins |
| Delete a scene, character, element or location | Whoever added it, or an admin |
| Delete a task or a shot | Project members and company admins |
| Add a note | Project members and company admins |
| Edit a note | Its author |
| Delete a note | Its author, or an admin |

## Shoot days and call sheets

| Action | Who |
| --- | --- |
| See shoot days | Project members |
| Add and change shoot days, schedules and calls | Crew |
| Delete a shoot day | Whoever added it, or an admin |
| Send a call sheet; turn the shared link on or off | Crew |
| See the full call sheet | Crew |
| See only your own call | Cast |
| Confirm a call | The person called |
| Read a personal link and confirm | Anyone with that link |
| Read the shared link | Anyone with that link |

## Journal (coming soon)

Private entries are seen only by the author and the people they share them with. Public entries are seen by everyone on the project.
